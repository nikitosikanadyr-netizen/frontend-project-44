# CRM Система управления клиентами

## Описание
CRM система для управления контактными данными клиентов.

## Функционал
- Просмотр списка клиентов в виде таблицы
- Добавление нового клиента
- Редактирование данных клиента
- Удаление клиента
- Поиск клиентов
- Сортировка по колонкам (почти не успеваю доделать простите)
- Управление контактами клиента (до 10 контактов)

## Технологии
- HTML5
- CSS3
- JavaScript (ES6+)

## API
Используется MockAPI.io для хранения данных

## Реализованные улучшения
- Анимация модального окна
- Валидация формы перед отправкой
- Индикация загрузки

## Запуск проекта
1. Клонировать репозиторий
2. Открыть index.html в браузере
